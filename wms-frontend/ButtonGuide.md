# 引导页线框按钮设计说明 (Modern Wireframe Button)

该按钮专为高品质网页引导页（Landing Page）设计，结合了极简主义与现代科技感。

## 1. 视觉设计语言 (Visual Design)

### 核心美学
- **线框结构 (Wireframe)**：采用透明背景与细边框，减少视觉重量，使页面看起来更加通透。
- **荧光色调 (Neon Glow)**：使用 `#bcf540`（极光绿）作为主色调，在深色背景下具有极强的穿透力和品牌感。
- **毛玻璃效果 (Glassmorphism)**：内置 `backdrop-filter: blur(5px)`，即使在复杂的背景图上也能保持文字的清晰度。

## 2. 交互功能说明 (Interaction Features)

### 动态反馈
1.  **悬停填充 (Hover Fill)**：
    - 鼠标悬停时，背景迅速填充为主色调，文字反色（变为黑色）。
    - 这种强烈的对比切换能瞬间捕捉用户注意力，明确指示可交互性。
2.  **流光溢彩 (Sliding Light)**：
    - 内部含有一层隐藏的线性渐变光效，悬停时会从左向右划过。
    - 模拟金属或玻璃反光的质感，提升设计的“昂贵感”。
3.  **霓虹光晕 (Outer Glow)**：
    - 悬停时通过 `box-shadow` 产生柔和的荧光光晕。
    - 赋予按钮体积感，使其仿佛悬浮在屏幕之上。
4.  **微动动画 (Micro-interaction)**：
    - 图标（箭头）在悬停时会向右微移 5px，暗示“前进”和“引导”的动作逻辑。

## 3. 使用场景 (Use Cases)
- **核心行动点 (Primary CTA)**：如“立即开始”、“探索更多”。
- **高端产品展示**：适合科技、工业管理（如 WMS）或创意类网站。

## 4. 技术实现
- **CSS3 变量**：易于全局调整颜色。
- **贝塞尔曲线**：使用 `cubic-bezier(0.23, 1, 0.32, 1)` 确保动画丝滑且具有动量感。
- **响应式**：采用 `inline-flex` 布局，自动适应文本长度。
